# Roblox Studio Factory 🏭

Le studio de jeux Roblox de Shad, piloté par un agent IA « directeur de studio ».

- **Le cerveau :** `AGENT_PROMPT.md` (rôle, boucle quotidienne, barèmes, règles Roblox, format du rapport).
- **Les jeux :** `games/<jeu>/` — chacun avec son code (Rojo + Luau), son fichier `.rbxlx` à ouvrir dans Roblox Studio, son README et son kit marketing.
- **Les rapports :** `reports/AAAA-MM-JJ.md` — un par jour : tendances, 2 concepts notés, prototypes, sélection, marketing, finances, décisions à prendre.
- **Les outils :** `tools/setup.sh` (installe Rojo + luau-lsp), `tools/check.sh games/<jeu>` (construit et vérifie).

## Règles d'or
2 prototypes par jour = objectif de production, **pas** 2 publications. Rien n'est publié (Roblox, réseaux sociaux) et aucun euro n'est dépensé sans le feu vert de Shad.
